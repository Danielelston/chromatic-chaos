---
name: triage
description: File Inbox notes into World, Lore, Characters, Player Notes or Sessions, or fold them into existing notes/companions.
---
`Inbox/` holds quick captures; raw files, PDFs, images and DM handouts belong in `Dropzone/` — point those at `/ingest`. For each file in `Inbox/`: decide the destination and show a table (file → destination → action) first.
- New player-authored info → move to the right folder with correct frontmatter.
- Info about a DM-owned note → convert into a companion via the `/propose` procedure, then remove the inbox item.
- Unsure → ask. Apply only after the user confirms the table. Never delete content; moves and merges only.
